Installing the Kiln runtime by hand
===================================

kiln-runtime-@VERSION@.zip is Kiln's runtime (internal version @RUNTIME_VERSION@): the dinput8.dll proxy, kiln-core,
the services, Kiln.Host and Kiln.Api, a private .NET runtime, the symbol definitions for the game client and the
dedicated server, Kiln.Admin, the parts that run other loaders' mods (EMF, EML, ShroudForge, Enshwick; installed by
default), and the samples (optional). The Kiln Launcher installs it for you (Play > Install, or Runtime); use these
steps for a dedicated server or when you do not use the launcher.

kilnctl (Linux: kilnctl, Windows: kilnctl.exe) installs it, keeps a receipt, backs up what it replaces, and can
uninstall it byte for byte. Check the zip first:

  kilnctl bundle verify kiln-runtime-@VERSION@.zip

Close the game or stop the server before installing.


Game client
-----------
  Linux (Proton):  ./kilnctl bundle install kiln-runtime-@VERSION@.zip --dir "<Steam library>/steamapps/common/Enshrouded" --real
  Windows:         kilnctl.exe bundle install kiln-runtime-@VERSION@.zip --dir "C:\Program Files (x86)\Steam\steamapps\common\Enshrouded" --real

  --real confirms a folder inside a Steam library. The client parts are installed by default (core, sigdb-client, emf, eml,
  shroudforge, enshwick).
  On Linux, Proton may need the launch option  WINEDLLOVERRIDES="dinput8=n,b" %command%  (Steam > Enshrouded >
  Properties > Launch options) so the game loads Kiln's dinput8.dll.
  Remove it again:  kilnctl bundle uninstall --dir "<the same folder>" --real


Dedicated server
----------------
  Only FTP or a file manager (a rented server), or no kilnctl: kiln-server-@VERSION@.zip, the server pack, holds just
  the server parts. Unzip it into the folder with enshrouded_server.exe; KILN-SERVER-README.txt inside has the steps.

  A kilnctl server on Linux (Wine):   ./kilnctl deploy <name> --bundle kiln-runtime-@VERSION@.zip
  Any server folder (Linux or Windows):
    kilnctl bundle install kiln-runtime-@VERSION@.zip --dir "<server folder>"

  The server parts, installed by default: core, sigdb-server, admin (Kiln.Admin, for the launcher's server pages), and
  emf, eml, shroudforge, enshwick (EMF, EML, ShroudForge and Enshwick mods). Add samples for the hello sample
  (--components with the full list). A folder inside a Steam library also needs --real.
  To keep a kilnctl server running and start it at boot: the systemd user units next to kilnctl (kiln@.service,
  kiln-backup@.service, kiln-backup@.timer; see docs/kiln/kilnctl.md, "systemd").


By hand, without kilnctl
------------------------
The zip holds the files at their place in the game folder (dinput8.dll, kiln/...) plus kiln-runtime.json, which lists
every file with its sha256 and component. Unzipping it into the game or server folder works, but nothing is backed up
and an existing dinput8.dll (another mod loader) is overwritten instead of chained. Prefer kilnctl. Unzipped raw, this
zip also puts every optional and client part into the folder; for a server, unzip kiln-server-@VERSION@.zip instead.
