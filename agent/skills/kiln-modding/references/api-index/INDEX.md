# Kiln mod API index (mod API 0.2.25)

Every public type and member of the mod API, one line each, to grep: a name (`BlockAt`), a word of what it does (`refusal`), a mod API (`0.2.15` finds what that release added). Then open that assembly's file: its name is the `KilnServices` entry (`Items.md` needs `<KilnServices>Items</KilnServices>`; `Api.md` needs none). A file that was too large is a map (`Blocks.md`) of its parts (`Blocks-items.md`).

- Type: `## Name `mod API` — first sentence of its XML doc`. Member: `- `signature` `mod API` — first sentence`. A member shows a mod API only when it differs from its type's; no mark at all: mod API 0.2.1 or older. `enum:` lists a whole enum's values. A property is one line (`{ get; init; }`).
- Names are short: `Kiln.` and `System.` left out, `!` (not null) too. Extension members (`Is.InCombat`, `Act.Flee`) are listed under the static class that declares them, written on their receiver.
- Left out: experimental API (`[Experimental("KILNX0nn")]`: lab and test members, API not proven in a client yet), compiler-made record members, overrides of object's members, a parameterless constructor without a doc. Not here: the game's own types (`Kiln.Ecs`, generated: docs/kiln/typegen.md).
- What each mod API number is: references/versions.md. Prose, rules and examples: the guides of the table. `docs/kiln/` pages are in the repository.
