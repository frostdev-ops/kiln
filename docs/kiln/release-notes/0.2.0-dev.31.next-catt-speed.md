# Kiln 0.2.0-dev.31.30: action speed (lane catt-speed)

Kiln now provides the framework for attack and action speed mods: a mod can make a player's melee attacks, bow shots
and tool swings faster or slower, and Kiln does the game-specific work on clients and dedicated servers. Players see
nothing new without a mod that uses it. Thanks to the Combat And Attack Tweaks author, whose native notes and mod are
the base of this work and its first user.

## Players and server admins

- **Nothing changes by itself.** Action speed does nothing until a mod sets a value. With no such mod, Kiln hooks
  nothing for it.
- **Speed mods in multiplayer.** With a mod such as Combat And Attack Tweaks on the dedicated server or the host, Kiln
  sends the speeds to every player who runs Kiln, and each player's own swing uses them, so it looks and plays right.
  The mod doesn't need a synced config for this. Players without Kiln, or on an older Kiln, see the server's results
  at the server's timing.
- **Very high speeds.** Values above about 3 to 5 times on busy dedicated servers are untested. Above 2x a fast melee
  swing can miss a target between two server ticks: Kiln does not sample hits between frames in this release.
- **Bows.** A new bow speed applies from the next draw; a draw in progress keeps its time.

## Modders

- **Mod API 0.2.28.** New in Kiln.Combat (namespace `Kiln`): `ActionSpeed`, `ActionKind`, `ActionSpeedChanged`,
  `ActionSpeedStatus`, exactly as in the preview SDK 0.2.0-dev.31.30-preview.1. Require
  `"kiln": ">=0.2.0-dev.31.30"`.
- **The calls.** `ActionSpeed.SetDefault(kind, m)` for every player (also later joins), `Set(player, kind, m)` for one
  player, `ClearDefault`, `Clear(player, kind)`, `Clear(player)`, `Get(player, kind)` (the effective value, any side),
  the `Changed` event, `Available` and `Status`. Kinds: `Melee` (light and heavy attacks, combos, recovery), `Bow`
  (draw, fire and the shot; not staffs or wands), `Tool` (axe, pickaxe and the like).
- **Rules.** Each mod's values are its own; across mods they multiply, clamped to 0.5 to 10 (`ActionSpeed.Min`,
  `ActionSpeed.Max`). A value outside that range throws. A mod's values go when it unloads, and a player's when they
  leave. Players only in this version. The server or the host sets values on the tick thread; on a joined client the
  setters throw `InvalidOperationException`.
- **What Kiln scales.** The action's sequence clock (hits, combos, recovery) and its animation together, and for a bow
  the fresh, skill-adjusted charge and fire durations. Kiln classifies the action from its trigger and its item's
  equipment slot type; any other action keeps the game's timing.
- **Melee sampling.** `ActionSpeed.MeleeSamplingAbove` is 2.0, but `Status.MeleeSampling` is false in this release
  (capability `combat.melee_sampling`: "planned: needs an in-game check first"). A mod may keep its own contact sampling
  for now and read the rate with `ActionSpeed.Get(player, ActionKind.Melee)`. Kiln's sampler follows in a later
  release, after an in-game check.
- **Capabilities.** `combat.action_speed` (sequence and graph), `combat.bow_timing`, `combat.melee_sampling`, and
  `combat.action_speed.prediction` (a game client).
- **Native.** A new table, `kiln.combat.speed` v1 (`kiln_action_speed.h`, published by kiln-combat.dll). New sigdb
  definitions `combat-speed.json` for client 26430625 and server 26430253, with every site verified statically
  (docs/re/action-speed.md).
- **Guides.** [Action speed](../modding/action-speed.md), the service section in
  [combat.md](../services/combat.md#action-speed), and [Combat And Attack Tweaks on Kiln's action
  speed](../modding/catt-action-speed.md), which lists which of their sites each call replaces.

## Not yet seen in a real game

- Action speed at all: host tests over fakes, static checks on both exes and managed tests only.
- A guest applying the server's speeds to its own swing (it relies on the same entity id in its prediction and client
  worlds as on the server).
- The graph scaling's look while a player attacks on the move (the whole animation takes the rate).
- The cost on a busy dedicated server at high speeds.
