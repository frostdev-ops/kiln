# Kiln 0.2.0-dev.31.20

A festive season look for the launcher, from the Monday after Thanksgiving to 7 January, a switch that keeps a server's web panel opening on this computer, and a fix for the server map's route panel.

## Players and server admins

- **Warm wishes for the season:** from the Monday after Thanksgiving through 7 January, the launcher's fire wears a festive mantel of lamps, candles and lanterns from many winter traditions, with snow falling outside the arch. Don't want it? Switch it off in Settings > General > Look > Festive season: it stays off for the rest of the season and comes back next season. With Animated fire off the mantel stands still; on a graphics card that can't draw the snow, the fire burns as on every other day, with the mantel.
- **Always open the web panel on this computer.** Under a server's Open web panel (Servers > Overview) a new switch keeps the panel opening on this computer, never at its hosted address (`https://<name>.kiln.nexus` or your own), and the launcher then doesn't check that address at all. Its line says why you might want it: hosted addresses go through frostdev.io's relay (encrypted end to end), and this computer's address only works from this computer. It is off by default, set per server (local and remote), and kept across restarts. While it is being saved, Open web panel waits, so a click right after it never opens at the hosted address.
- **The route panel on a server's Map can be closed again.** On World > Map with no map art, the route panel lay under the "no map art" notice, so its ✕ could not be clicked. It now sits below the notice, and above the pointer's coordinates when a long notice fills the map.

## Modders

- No mod API change: mod API 0.2.25, as in 0.2.0-dev.31.19. The MDK packs are 0.2.0-dev.31.20.
- Npcs.Say and Npcs.Speech are now seen working in a real game (thanks Marshall/Ryrin, Living Larder): Replace lines in the game's own bubble with no voice-over, a Say line, and the game's greetings back after Clear. Not seen yet: Suppress, a Say over an NPC that is not the target, and how far a Say shows (docs/kiln/services/npc-speech.md).
- Launcher: the festive season is date-gated in `shell/season.ts`: from 00:00 on the Monday after the fourth Thursday of November to 00:00 on 8 January, in the player's local time, re-checked every 10 minutes; the Thanksgiving turkey wins on its weekend, so the two never show together. In the browser mock `?theme=festive` / `?theme=normal` force it on or off, and `?theme=auto` lets the date decide (the turkey's too) even under automation, where (`navigator.webdriver`) it stays off otherwise. The Settings switch keeps the player's opt-out in local storage (`kiln.festive.off`, the year the season started). Every other day the fire's shader is the same as in 0.2.0-dev.31.19 (`FRAG`, `FRAG_TURKEY`); the season's is `FRAG_FESTIVE`, and a driver that cannot build it (at the compile or the link) gets `FRAG`.
- Launcher: `admin_web_panel_settings` (serverId) and `admin_web_panel_settings_set` (serverId, settings) read and save a server's `WebPanelSettings {alwaysLocal}`, kept in the launcher data folder's `web-panel-settings.json` (`{format: 1, servers: {<serverId>: {alwaysLocal}}}`, written atomically under a lock; an unknown server is `not_found`). While `alwaysLocal` is on, `admin_open_web_panel`'s `route: 'auto'` is `'local'`: no check, the panel's `public` address is never contacted, `fallback` is null. A file that is there but can't be read counts as on for every server and is never replaced: a change is refused (`parse` or the reading error, the file's path in `detail`) until the file is fixed or deleted (contracts.md).
- `@kiln/admin-ui` map: the no-art banner (`.ka-map-noart`) and the route panel (`.ka-map-route`) now flow down one column at the top of `.ka-map-area` (12 px from its top, 56 px from each side, ending 48 px above its foot), so the route panel stands below the banner instead of under it. The banner keeps its inline `z-index: 1001`, so a host rule that finds it by that (Kilnwarden's) still matches; its other inline values moved into `map.css`.

## Not yet seen in a real game

- "Always open the web panel on this computer" from the desktop launcher with a real hosted Kilnwarden, and for a remote (SSH) server; Kiln's tests and the browser mock only, no Windows run.
- The route panel below a real Kilnwarden's no-art banner in the desktop launcher; seen in the browser mock and the map harness with Kilnwarden's hide rules.
